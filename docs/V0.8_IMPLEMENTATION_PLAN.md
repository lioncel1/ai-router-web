# AI Router v0.8 开发实施计划

**版本：v0.8-planning**

## 1. 版本目标

将 AI Router 从当前多入口调用模式升级为以 Task 为核心的统一执行平台。

当前：

用户 → Chat / Auto / Dialogue → Provider

目标：

用户 → Task Engine → Workflow Runtime → Provider Runtime → Message /
Event / Audit Storage

------------------------------------------------------------------------

## 2. v0.7现状

已具备：

-   Gemini Web调用
-   ChatGPT Web调用
-   Conversation管理
-   外部会话导入
-   Auto异步任务
-   Dialogue双模型交流
-   Graceful Stop

主要问题：

-   任务状态依赖内存
-   历史记录分散
-   缺少统一任务模型
-   Provider与Transport未完全抽象

------------------------------------------------------------------------

## 3. v0.8开发原则

### 保持兼容

-   不破坏v0.7功能
-   保留已有Conversation
-   保留Web模型能力

### 渐进式改造

采用：

旧系统 → 兼容层 → 新Task系统

不进行一次性重构。

------------------------------------------------------------------------

# 4. 开发阶段

## Phase 1：数据层

新增SQLite：

    ai_router.db

第一阶段表：

    tasks
    messages
    task_events
    provider_calls

目标：

-   保存任务生命周期
-   保存模型调用记录
-   保存消息历史
-   支持服务重启恢复

------------------------------------------------------------------------

## Phase 2：Task Engine

新增统一任务管理：

功能：

-   创建Task
-   更新状态
-   保存结果
-   请求停止
-   查询历史

统一：

Chat：

    Task
     └ ProviderCall
     └ Message

Auto：

    Task
     └ Workflow阶段
     └ ProviderCall

Dialogue：

    Task
     └ Message x N

------------------------------------------------------------------------

## Phase 3：Task Center

增加：

    GET /api/tasks
    GET /api/tasks/{id}
    POST /api/tasks/{id}/stop

页面支持：

-   历史任务列表
-   状态查看
-   耗时查看
-   模型调用链查看
-   错误查看

------------------------------------------------------------------------

## Phase 4：Provider抽象

目标：

统一：

    Provider
     |
     +-- Web
     |
     +-- API
     |
     +-- Local

例如：

    ChatGPT
     ├ Web
     └ API

    Gemini
     ├ Web
     └ API

支持未来：

Web失败 → API备用。

------------------------------------------------------------------------

## Phase 5：Workflow准备

v0.8暂不完整实现Workflow Engine。

仅预留：

    workflow_id
    workflow_version
    workflow_run_id

未来统一：

-   Auto
-   Dialogue
-   Agent流程

------------------------------------------------------------------------

## Phase 6：客户端准备

核心保持：

    AI Router Gateway API

未来接入：

-   Web
-   Desktop
-   微信
-   飞书
-   移动端

------------------------------------------------------------------------

# 5. v0.8不做事项

暂不实现：

-   微信机器人
-   飞书机器人
-   Desktop客户端
-   Workflow编辑器
-   Agent自主学习
-   多用户权限

原因：

优先稳定核心执行链。

------------------------------------------------------------------------

# 6. v0.8验收标准

数据：

-   所有任务进入SQLite
-   历史任务可查询
-   重启不丢失

功能：

-   Chat正常
-   Auto正常
-   Dialogue正常
-   Stop正常

架构：

-   Task统一入口
-   Provider/Web/API分离
-   支持后续客户端接入

------------------------------------------------------------------------
